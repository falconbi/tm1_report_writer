# Tech Gotchas

## Visual Preview Not Showing (2026-04-11)

### Symptom
Visual preview in builder shows placeholder text instead of actual chart/KPI rendering.

### Root Cause
The `VisualRenderer` component (which uses Recharts to render actual charts) wasn't imported or used in `CanvasPanel.tsx`. The visual store WAS working and data WAS loading correctly, but CanvasPanel was just showing text placeholders.

### Fix Applied
1. Added import: `import VisualRenderer from '../shared/VisualRenderer'`
2. Rendered the component: `<VisualRenderer definition={visualDef} dataset={visualDataset} />`

### Lesson
When adding new tab previews (reports, visuals, notes, etc.), need to:
1. Import the actual renderer component
2. Render the component, not just text placeholders
3. Verify with console logs that store data is loading before checking UI
