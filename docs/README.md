# TM1 Report Writer

**TM1 Report Writer** is a financial reporting application by Falcon BI. It turns governed TM1 cube data into polished, exportable, professional-grade report packs — ready for finance teams, board presentations, and regulatory submissions.

---

## What it does

Connect to your IBM Planning Analytics (TM1) cubes and build structured financial reports without writing a single line of MDX. Compose multiple reports, visuals, and commentary into paginated report packs. Publish, lock, and distribute — all from a browser.

---

## Key features

- **Report Builder** — structured financial tables with full column, row, and number formatting control
- **Visuals** — KPI tiles and charts connected directly to TM1 data
- **Pack Composer** — drag-and-drop page layout with sections, slots, and per-page orientation
- **PDF Export** — server-side PDF generation with correct A4 portrait and landscape pages
- **Pack Locking** — freeze data snapshots for audit and regulatory packs
- **Roll Forward** — create next period's pack from a locked template in seconds
- **CSV Upload** — bring in data from outside TM1 using CSV files

---

## Who uses it

| Role | What they do |
| --- | --- |
| **Report Designer** | Builds and publishes reports and visuals in the Builder |
| **Pack Composer** | Assembles artifacts into paginated packs in the Composer |
| **Finance User** | Reads published packs in the Viewer |
| **IT Administrator** | Deploys and maintains the application |
